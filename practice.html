💬 What is an input statement?

So far, our programs have used information that we have written directly into the code. But what if we want the person using the program to enter some information?

We can use Python's input() command to ask the user a question and allow them to type an answer.

How does it work?

Here is a simple example:

name = input("What is your name? ")

There are three important parts:

  1. name is the variable where we store the answer.
  2. input() tells Python to ask the user for some information.
  3. "What is your name? " is the question that the user will see.

If the user types Alex, Python stores Alex inside the variable called name. 

name = input("What is your name? ")
print(name)

The program would then display: 

What is your name? Alex
Alex
⭐ Remember: The variable stores the answer that the user types.

Think of it like this:

variable = input("question")

The user sees the question, types an answer, and Python stores that answer in the variable.

➗ Python Maths Symbols

Python can perform maths just like a calculator. However, some of the symbols are different from the ones you normally use in maths.

Four important maths symbols

Maths Python Example
Addition + 5 + 3
Subtraction - 5 - 3
Multiplication * 5 * 3
Division / 6 / 3

Multiplication

In normal maths, you might write: 

5 × 3

Python does not use the × symbol. Instead, Python uses the asterisk: 

5 * 3

So: 

answer = 5 * 3
print(answer)

would print: 

15

Division

In normal maths, you might write: 

12 ÷ 3

Python uses a forward slash / instead: 

12 / 3

For example: 

answer = 12 / 3
print(answer)

would print: 

4.0
⭐ Remember: * means multiply and / means divide.

🔢 Why do we need int()?

There is something important you need to know about input().

When Python gets information using input(), it normally treats the answer as text, even if the user types a number.

For example...

age = input("How old are you? ")

If the user types: 

13

Python has stored "13" as text rather than the number 13.

This can cause a problem when we want to do maths.

We can use int() to fix this.

int() tells Python:

"Treat this as a whole number."

For example:

age = int(input("How old are you? "))

Now, if the user types 13, Python stores it as the number 13.

Why does this matter?

We can now use the value in a calculation. 

age = int(input("How old are you? "))

next_year = age + 1

print(next_year)

If the user enters 13, Python calculates: 

13 + 1

and prints:

14
⭐ Remember: input() gets information from the user. int() converts that information into a whole number so that we can do maths with it.

The pattern to remember

variable = int(input("Question: "))

You will use this pattern a lot when making programs that ask users to enter numbers.
